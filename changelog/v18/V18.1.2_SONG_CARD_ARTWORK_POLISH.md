# Beat UP! 18.1.2 — Song Card & Artwork Polish

Basis: 18.1.1. Patch project Godot, bukan updater executable game.

- Lebar song card dibatasi sekitar 940 px pada layar besar agar banner tidak menjadi strip yang terlalu panjang.
- Layar lebih kecil tetap memakai lebar yang tersedia sehingga judul dan artis aman.
- Artwork mendapat focal crop tambahan di sisi kanan song card agar karakter dan cover tetap dapat dikenali.
- Carousel tetap rata kanan dan mempertahankan kurva berdasarkan jarak dari lagu terpilih.
- Jarak judul dengan artis dirapatkan; judul panjang tetap maksimal dua baris.
- Scrollbar yang tidak diperlukan di Chart Overview dihilangkan.
- Angka normal, reverse, SPACE, dan musical sections diperbesar; labelnya dibuat lebih redup.
- Batas atas daftar memakai fade 18 px agar potongan kartu di bawah toolbar terlihat disengaja.

## Instalasi

Tutup game dan Godot. Extract ZIP patch ke folder terpisah. Jalankan apply-v18.1.2.bat lalu masukkan folder Beat UP! 18.1.1 yang berisi project.godot.

Patcher memeriksa versi dan SHA256 file terkait, membuat backup di samping folder project sebelum menulis, serta rollback otomatis jika pemasangan gagal. File terkait yang sudah dimodifikasi membuat patch ditolak agar perubahan lokal tidak tertimpa. project.godot hanya diubah nilai versinya. Payload tidak berisi musik, artwork, chart, atau manifest JSON.

## Validasi

Godot headless berhasil menjalankan pengujian layout 1280×720, 1600×900, dan 1920×1080; batas lebar kartu; judul dua baris; jarak judul–artis; fade carousel; Chart Overview tanpa scrollbar; difficulty; ranking 20 run; filter; pergantian 4K/8K; serta dua hasil permainan yang langsung kembali ke library tanpa restart. Patcher PowerShell diuji untuk install, reapply, versi salah, file lokal berubah, backup, dan rollback tersimulasi.

Lingkungan headless tidak menyediakan texture viewport untuk screenshot, sehingga hasil visual akhir tetap perlu dilihat setelah patch dijalankan di Godot Windows.
