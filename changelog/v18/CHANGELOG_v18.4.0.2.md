# Beat UP! v18.4.0.2 — Note Palette Revert

Base version: v18.4.0.1

## Changed

- Restored the exact v18.3.0 note palette.
- Note bodies are dark navy again instead of off-white.
- Direction symbols are bright off-white again instead of dark.
- Preserved the established semantic outlines: blue for normal, orange for
  diagonal, red for reverse, and gold for SPACE.
- Kept all v18.4 interface changes and the v18.4.0.1 parser hotfix.

## Compatibility

- Patch target: Beat UP! v18.4.0 or v18.4.0.1 source project.
- Music, charts, settings, records, replays, and telemetry are not overwritten.
- No build-manifest JSON is included.
