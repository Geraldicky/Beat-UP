# Beat UP! v18.1.2.3 — Home-Style Now Playing in Song Library

- Replaces the experimental Song Library-specific Now Playing treatment.
- Song Library now uses the same full-width top bar geometry, spacing, typography, progress bar, and transport icons as the Home screen.
- The bar stays at `(0, 0)` and scales to the same 36–42 px responsive height used by Home.
- Library content is shifted below the shared top bar rather than overlapping it.
- Previous / Play-Pause / Next control the global MusicSession; previous/next move through the currently filtered Song Library order.
- No chart, background, or audio assets are modified.
- No manifest JSON is created.
