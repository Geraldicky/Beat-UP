# Beat UP! 18.1.1 — Song Library Visual Hierarchy

Basis: 18.1.0. Patch project Godot, bukan updater executable game.

- Judul lagu dapat membungkus tepat dua baris sehingga judul panjang tetap terbaca.
- Lebar panel informasi menjadi 470 px pada tampilan compact dan 570 px pada layar besar.
- Detail chart dikumpulkan dalam satu kartu ringkas tanpa kalimat petunjuk Chart Studio.
- Carousel memakai indentasi 0–72 px berdasarkan jarak dari pilihan, sehingga lagu aktif lebih mudah ditemukan.
- Lagu terpilih dibuat lebih terang dengan garis aksen 5 px; kartu lain diredupkan secara konsisten.
- Tinggi kartu menjadi 60 px, pilihan 76 px, dan difficulty 36 px.
- Difficulty menggunakan kolom yang lebih rapi serta label NOTES yang eksplisit.
- Ditambahkan jarak di awal area scroll agar kartu teratas tidak menempel pada toolbar.
- Search, filter, action bar dan tombol sekunder dipadatkan agar hierarki PLAY lebih jelas.

## Instalasi

Tutup game dan Godot. Extract ZIP patch ke folder terpisah. Jalankan apply-v18.1.1.bat lalu masukkan folder project Beat UP! 18.1.0 yang berisi project.godot.

Patcher memeriksa versi dan SHA256 file terkait, membuat backup di samping folder project sebelum menulis, dan memulihkan perubahan otomatis jika pemasangan gagal. Perubahan lokal pada file terkait membuat patch ditolak agar tidak tertimpa. project.godot hanya diubah nilai versinya. Tidak ada musik, artwork, chart, atau manifest JSON dalam payload.

## Validasi

Uji Godot headless meliputi 1280×720, 1600×900, dan 1920×1080; judul panjang dua baris; kurva carousel; label note difficulty; ranking 20 run; pergantian 4K/8K; filter; empty search; dan dua hasil permainan yang kembali ke Song Library tanpa restart. PowerShell patcher diuji untuk install, reapply, versi salah, file lokal berubah, isi backup, dan rollback setelah kegagalan tersimulasi.

Renderer headless di lingkungan pengujian tidak menyediakan texture viewport, jadi pemeriksaan screenshot final tetap dilakukan setelah patch dijalankan pada Godot Windows. Peringatan resource/ObjectDB lama masih muncul ketika test scene ditutup dan belum diklaim selesai pada patch UI ini.
