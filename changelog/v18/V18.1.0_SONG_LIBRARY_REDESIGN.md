# Beat UP! 18.1.0 — Song Library Redesign

Basis: 18.0.0.2. Patch project Godot, bukan updater executable game.

- Panel lagu 430/520 px; browser memakai sisa ruang. Layout diuji mulai 1280×720.
- Judul, artis, difficulty, BPM, durasi dan jumlah notes tersusun ringkas.
- Kartu lagu 64 px / pilihan 72 px; difficulty 38 px, subtitle tidak terpotong.
- Details memakai breakdown teks yang dapat di-scroll.
- Ranking menampilkan satu run per baris, sort Score/Newest, mengikuti mode aktif.
- Klik run untuk rincian judgement. WATCH REPLAY hanya untuk run yang identitasnya cocok dengan replay terbaru.
- Search/Sort tetap terlihat; filter tambahan bisa dibuka dan chip dapat dihapus.
- Action bar global: Back, Mods, Practice, Options, Play. Options berisi Import, Refresh, Chart Studio, Export Playtest dan Latest Replay.
- Layout dipisahkan ke library_composition.gd; controller lama tetap menangani katalog/navigasi/records.
- Result snapshot menyimpan run_id untuk kecocokan replay. Tidak mengubah kalkulasi skor.
- Callback accessibility menggunakan instance ID agar tidak mengakses node daftar yang sudah dihapus.

## Instalasi
Tutup game dan Godot. Extract ZIP patch ke folder terpisah. Jalankan apply-v18.1.0.bat lalu masukkan folder yang berisi project.godot versi 18.0.0.2. Buka kembali project di Godot setelah patch berhasil.

Patcher memeriksa versi dan SHA256 file terkait, membuat backup di samping folder project sebelum menulis, serta memulihkan file jika proses gagal. Perubahan lokal pada file yang akan diganti membuat patch ditolak. project.godot hanya diubah nilai versinya; pengaturan lain dipertahankan. Tidak ada musik, artwork atau chart dalam payload.

## Batasan dan validasi
Godot 4.6 headless digunakan untuk uji parse, batas layout 1280×720/1600×900/1920×1080, pergantian tab, ranking 20 run, mode, filter dan empty search. Project tetap mendeklarasikan fitur Godot 4.7 sesuai basis pengguna. Pengujian ini bukan pemeriksaan rendering visual atau pengujian Windows; BAT perlu dijalankan pada Windows pengguna. PowerShell diuji pada Linux.

Replay tetap memakai penyimpanan latest-only yang sudah ada. Record lama tanpa run_id tidak diberi tombol replay yang menyesatkan; replay lama masih bisa diakses dari Options jika tersedia. Resolusi di bawah 1280×720 belum menjadi target. Fokus update adalah Song Library; gameplay, generator dan asset tidak dirombak.

Hasil tambahan: uji live records berhasil untuk dua hasil permainan, kembali via Result dan Main Menu, serta pemisahan 4K/8K. Uji PowerShell berhasil untuk install, reapply, versi salah, file lokal berubah, isi backup, dan rollback setelah simulasi kegagalan. Masih ada peringatan resource/ObjectDB saat teardown tes; belum diklaim bebas kebocoran resource.
