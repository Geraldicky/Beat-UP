# Beat UP! 18.1.2.1 — Song List Interaction Hotfix

Basis: 18.1.2.

- Menghapus focal crop kedua yang menimbulkan sambungan gelap seperti bayangan pada setiap song card.
- Menghapus gradient fade 18 px yang terlihat seperti shadow di ujung atas song list.
- Scroll manual melalui mouse wheel dan scrollbar langsung membatalkan auto-centering agar daftar tidak ditarik kembali dan terasa tersendat.
- Perhitungan batas lebar card menggunakan lebar WheelColumn, sehingga batas sekitar 940 px bekerja konsisten di Windows.
- Memulihkan tinggi adaptif judul: judul satu baris tetap terlihat dan judul panjang mendapat ruang dua baris.

## Instalasi

Tutup game dan Godot. Extract ZIP patch ke folder terpisah, jalankan apply-v18.1.2.1.bat, lalu masukkan folder Beat UP! 18.1.2 yang berisi project.godot.

Patcher memverifikasi versi dan SHA256, membuat backup sebelum menulis, serta rollback otomatis ketika pemasangan gagal. File terkait yang sudah dimodifikasi akan ditolak agar perubahan lokal tidak tertimpa. project.godot hanya diubah nilai versinya. Payload tidak berisi musik, artwork, chart, atau manifest JSON.

## Validasi

Godot headless berhasil menjalankan layout 1280×720, 1600×900, dan 1920×1080; batas lebar card; scroll manual membatalkan auto-centering; tanpa overlay shadow; judul Blue Zenith satu baris; judul U.N. Owen dua baris; ranking 20 run; pergantian 4K/8K; dan live record tanpa restart. Patcher PowerShell diuji untuk install, reapply, versi salah, file lokal berubah, backup, dan rollback tersimulasi.
