# Beat UP! 18.1.2.2 — Song Library Now Playing Layout

Basis: 18.1.2.1.

- Menambahkan Now Playing card tipis di bagian atas Song Library dengan judul, artis, progress, durasi, previous, play/pause, dan next.
- Card memakai MusicSession global yang sudah ada; tidak membuat audio player kedua dan tidak me-restart lagu saat UI hanya diperbarui.
- Previous/next berpindah mengikuti urutan lagu yang sedang tampil setelah search/filter/sort.
- Play/pause mengontrol preview aktif; jika belum ada track aktif, tombol play memulai preview lagu terpilih.
- Posisi layar diseimbangkan ulang setelah penambahan card: margin atas dipadatkan, lebar panel detail sedikit dikurangi, jarak detail–browser dirapikan, dan action bar tetap berada di bawah tanpa overlap.
- Pada viewport compact, label NOW PLAYING disembunyikan dan progress dipendekkan agar layout tetap muat.
- Tidak mengubah chart, artwork, save data, ranking identity, atau audio library.
- Tidak menambahkan manifest JSON.

## Validasi

Patch dibangun langsung dari ZIP Beat UP! 18.1.2.1 yang diberikan pengguna. Static source checks dan simulasi apply terhadap baseline tersebut lolos. Godot executable tidak tersedia di environment build ini, jadi visual/runtime final perlu diverifikasi sekali di Godot Windows setelah apply.
