# Beat UP! v17.4.25.4 — Main Menu Top Bar Refinement

## Fixes
- Fixes the bug where the top bar only appeared after entering gameplay and returning to Main Menu.
- The cold-launch Main Menu reveal now animates `NowPlayingCard` from the first visit.

## UI Changes
- Reworks the top bar into a flatter osu!-style horizontal strip.
- `CURRENT PLAYING`, title, and artist now flow horizontally instead of stacking vertically.
- Transport controls are now icon-style (`◀`, `❚❚`/`▶`, `▶`) without square button chrome.
- Main menu stack is nudged down slightly to balance the new top bar.

## Technical Notes
- No manifest JSON files were created.
