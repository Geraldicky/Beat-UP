# Beat UP! v17.4.25 — Random Song-Art Main Menu Redesign

## Main Menu
- Rebuilt the Main Menu around full-screen song artwork instead of the previous dashboard/grid background.
- Every Main Menu visit chooses a random built-in Song Library background and avoids immediately repeating the previous artwork when possible.
- The first Main Menu visit after launch is randomized as well.
- Added lightweight song/artist attribution for the currently displayed background.
- Reworked the composition into an osu!-inspired flow: a large Beat UP! diamond/logo anchor with the action list unfolding beside it.
- Removed the large opaque Main Menu panel language so the selected artwork remains the visual focus.
- Added restrained scrims, layered Beat UP! diamond outlines, and reactive BGM bars over the artwork.
- Updated focus motion and menu-card styling to remain readable over arbitrary song art.

## Scope
- No gameplay, scoring, timing, chart-generation, telemetry schema, or chart data changes.
- All 42 built-in charts remain unchanged.
- No manifest JSON is generated or included.
