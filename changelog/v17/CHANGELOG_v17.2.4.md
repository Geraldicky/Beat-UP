# Beat UP! v17.2.4 — Song Browser Final Micro-Polish

## Scope
UI-only refinement on top of v17.2.3. No chart, background, progression, or gameplay changes.

## Changes
- Collapsed song rows are ~12.5% shorter while the selected row keeps its stronger height.
- Unselected song rows use lower fill/alpha so the selected song has clearer hierarchy.
- Selected song + difficulty rows are grouped more tightly with smaller gaps and inset.
- Difficulty rows are slightly shorter and visually quieter when not selected.
- Redundant `VISIBLE / TITLE A–Z` browser header is hidden, moving the search/filter toolbar to the top of the browser area.
- Personal Best block width reduced from 348 px to 264 px; metric cards reduced and spacing tightened.
- Random Mode control reduced to a smaller, lighter secondary toggle.
- Song-list scrollbar reduced to 2 px with invisible track and subtler grabber.
- Song-list vertical spacing reduced for higher information density.
- Version bumped to 17.2.4.

## Frozen systems
- 39 charts unchanged.
- 13 song backgrounds unchanged.
- No gameplay/timing/progression logic changes.
