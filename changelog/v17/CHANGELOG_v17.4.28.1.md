# Beat UP! v17.4.28.1 — Top Bar Transport Polish

## Focus
Refined the Now Playing top bar, especially the transport controls.

## Changes
- Increased top bar height for cleaner spacing.
- Increased left/right and top/bottom content padding inside the top bar.
- Expanded the track progress bar width slightly.
- Increased transport button hit area from 28x28 to 36x36.
- Increased spacing between transport buttons.
- Refined the transport icon drawing so prev / pause / next read more cleanly.
- Added a subtle hover / pressed halo behind transport buttons.
- Slightly improved title, artist, and duration text readability.
- Slightly deepened the top bar panel background for better contrast over bright artwork.
