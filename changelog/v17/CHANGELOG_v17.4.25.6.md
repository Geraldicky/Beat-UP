# Beat UP! v17.4.25.6 — Diamond Edge Waveform + Slim Top Bar

## Summary
- Restores the top bar to a long horizontal format while making it slimmer vertically.
- Removes the bottom waveform.
- Reintroduces waveform bars that attach directly to the four edges of the Beat UP! diamond, closer to the osu!-style wraparound feel.

## UI Changes
- Top bar is wider again and pinned to the top, but with reduced height.
- Progress bar and duration text remain in the top bar.
- Diamond waveform bars now start directly from the diamond edges and extend outward.
- No bottom waveform is drawn anymore.

## Notes
- No manifest JSON files were created.
